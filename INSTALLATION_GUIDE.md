# Руководство по установке и запуску Telegram-бота для получения новостей

## Текущее состояние проекта

Все файлы бота успешно созданы:

1. `Cargo.toml` - конфигурационный файл с зависимостями
2. `src/main.rs` - основной файл с полной логикой бота
3. `README.md` - подробная документация
4. `.env.example` - пример файла с переменными окружения

## Требования к системе

- Rust (версия 1.70 или новее)
- Cargo (устанавливается вместе с Rust)
- Git (для получения API-ключей)

## Шаги для запуска бота

### 1. Установка Rust и Cargo

В системе могут возникнуть проблемы с установкой Rust из-за нехватки памяти или других ресурсов. В таком случае рекомендуется:

#### Вариант A: Установка через пакетный менеджер (если возможно)
```bash
sudo apt update
sudo apt install rustc cargo
```

#### Вариант B: Установка через rustup (рекомендуется)
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env
```

### 2. Получение API-ключей

#### Токен Telegram-бота:
1. Найдите в Telegram бота @BotFather
2. Отправьте ему команду `/newbot`
3. Следуйте инструкциям для создания нового бота
4. Выберите имя и username для бота
5. BotFather вышлет вам токен в формате `1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ`

#### API-ключ для новостей:
1. Перейдите на сайт NewsAPI: https://newsapi.org/
2. Зарегистрируйтесь на сайте, чтобы получить бесплатный API-ключ
3. После регистрации вы получите API-ключ

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта со следующим содержимым:

```
TELEGRAM_BOT_TOKEN=ваш_токен_бота_здесь
NEWS_API_KEY=ваш_api_ключ_новостей_здесь
```

Замените `ваш_токен_бота_здесь` на токен, полученный от @BotFather, и `ваш_api_ключ_новостей_здесь` на API-ключ от NewsAPI.

### 4. Запуск бота

1. Убедитесь, что вы создали файл `.env` с необходимыми переменными окружения
2. В корне проекта выполните команду:

```bash
cargo run
```

Бот начнет принимать сообщения от пользователей в Telegram.

## Возможные проблемы и их решения

### Проблема: "TELEGRAM_BOT_TOKEN не найден в переменных окружения"
**Решение:** Убедитесь, что вы создали файл `.env` в корне проекта и правильно указали токен бота.

### Проблема: "NEWS_API_KEY не найден в переменных окружения"
**Решение:** Убедитесь, что в файле `.env` присутствует переменная `NEWS_API_KEY` с действительным значением.

### Проблема: "Новостей по вашему запросу не найдено"
**Решение:** Попробуйте изменить формулировку темы или использовать более общее понятие.

### Проблема: "Ошибка при получении новостей. Попробуйте позже."
**Решение:** Проверьте подключение к интернету, действительность API-ключа и корректность токена бота.

### Проблема: Ошибки компиляции или установки Rust
**Решение:** 
- Попробуйте увеличить количество доступной памяти
- Используйте минимальную установку Rust: `rustup toolchain install stable --profile minimal`
- Проверьте, что в системе достаточно свободного места

## Функциональность бота

- Команда `/start` — перезапуск бота с приветственным сообщением
- Команда `/help` — краткая справка о боте
- Ввод темы (например, "спорт", "технологии", "политика") — поиск новостей по этой теме
- Команды "следующая" или "next" — переход к следующей новости
- Команды "предыдущая" или "previous" — переход к предыдущей новости

## Структура проекта

- `src/main.rs` — основной файл с логикой бота
- `Cargo.toml` — файл зависимостей и настроек проекта
- `.env` — файл с секретными переменными (токенами)
- `README.md` — документация по использованию
- `INSTALLATION_GUIDE.md` — это руководство

## Используемые библиотеки

- `teloxide` — для взаимодействия с Telegram Bot API
- `reqwest` — для выполнения HTTP-запросов к NewsAPI
- `serde` — для сериализации/десериализации JSON-данных
- `tokio` — для асинхронного выполнения
- `log` и `env_logger` — для логирования событий
- `dotenv` — для загрузки переменных окружения из файла `.env`
