# Архитектура Telegram-бота для получения новостей

## Общая структура

Проект представляет собой Telegram-бота на языке Rust, который позволяет пользователям получать новости по заданным темам. Бот использует NewsAPI для получения новостных данных и teloxide для взаимодействия с Telegram.

## Структура проекта

```
/workspace/
├── Cargo.toml          # Файл конфигурации и зависимостей
├── README.md           # Основная документация
├── .env.example        # Пример файла с переменными окружения
├── src/
│   └── main.rs         # Основной файл с логикой бота
└── ARCHITECTURE.md     # Данный файл
```

## Основные компоненты

### 1. Зависимости (Cargo.toml)

- `teloxide` - фреймворк для создания Telegram-ботов
- `reqwest` - библиотека для HTTP-запросов к NewsAPI
- `serde` - сериализация/десериализация JSON
- `tokio` - асинхронное выполнение
- `log`, `env_logger` - логирование
- `dotenv` - загрузка переменных окружения

### 2. Основные структуры (main.rs)

#### UserState
Сохраняет состояние для каждого пользователя:
- `topic` - тема, по которой запрашиваются новости
- `page` - текущая страница (индекс новости)
- `news` - массив новостей

#### NewsItem
Представляет отдельную новость:
- `title` - заголовок
- `description` - краткое описание
- `url` - ссылка на новость
- `url_to_image` - изображение к новости (опционально)

#### Command
Перечисление команд бота:
- `Start` - начать работу
- `Help` - получить справку

### 3. Основные функции

#### main()
- Инициализирует логирование
- Загружает переменные окружения
- Создает экземпляр бота
- Запускает обработку сообщений

#### handler()
- Обрабатывает входящие сообщения
- Определяет тип сообщения (команда, навигация, тема)
- Вызывает соответствующие функции

#### get_and_send_news()
- Формирует запрос к NewsAPI
- Обрабатывает ответ
- Сохраняет новости в состоянии пользователя
- Отправляет первую новость

#### send_single_news()
- Форматирует и отправляет одну новость пользователю
- Включает заголовок, описание, изображение и ссылку

## Поток выполнения

1. Пользователь отправляет команду `/start`
2. Бот отправляет приветственное сообщение
3. Пользователь вводит тему для поиска новостей
4. Бот формирует запрос к NewsAPI
5. Полученные новости сохраняются в состоянии пользователя
6. Бот отправляет первую новость
7. Пользователь может использовать команды "следующая"/"предыдущая" для навигации
8. При каждой команде навигации отправляется следующая/предыдущая новость

## Обработка ошибок

- Если новостей по запросу не найдено, бот сообщает об этом
- Если NewsAPI возвращает ошибку, бот сообщает о проблеме с получением новостей
- Если сообщение не является текстовым, бот запрашивает ввод текста

## Безопасность

- API-ключи и токены бота хранятся в переменных окружения
- Используется файл .env (не включен в репозиторий)
- Пример .env.example предоставлен для настройки

## Масштабируемость

- Использование глобального состояния с мьютексом позволяет обрабатывать несколько пользователей
- Асинхронные функции обеспечивают производительность
- Четкое разделение ответственности между функциями
