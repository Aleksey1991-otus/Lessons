# Сводка проекта: Telegram-бот для получения новостей

## Описание
Создан Telegram-бот на языке Rust, который позволяет пользователям получать актуальные новости по интересующим их темам.

## Структура проекта
```
/workspace/
├── Cargo.toml                 # Файл зависимостей и настроек проекта
├── README.md                  # Документация проекта
├── .env.example              # Пример файла с переменными окружения
├── src/
│   └── main.rs               # Основной файл с логикой бота
```

## Особенности реализации

### 1. Основной функционал
- Приветствие пользователя при запуске: "Здравствуйте, какие новости вы хотите узнать?"
- Обработка команд `/start` и `/help`
- Получение темы от пользователя (например, "спорт", "технологии", "политика")
- Отображение новостей в виде карточек с заголовком, описанием и изображением
- Постраничная навигация с кнопками "следующая" и "предыдущая"

### 2. Архитектура
- Использование асинхронных методов (async/await)
- Глобальное хранилище состояний пользователей для поддержки навигации
- Обработка ошибок (отсутствие новостей, проблемы с API)
- Комментарии на русском языке для всех функций и структур

### 3. Используемые библиотеки
- `teloxide` v0.17.0 - для взаимодействия с Telegram Bot API
- `reqwest` v0.12.24 - для получения данных из новостных API
- `serde` v1.0 - для сериализации/десериализации JSON
- `tokio` v1.48.0 - для асинхронности
- `log`, `env_logger` - для логирования
- `dotenv` - для работы с переменными окружения
- `once_cell` - для глобального хранилища состояний

### 4. Безопасность
- Использование .env файла для хранения API-ключей
- Нет хардкода чувствительных данных
