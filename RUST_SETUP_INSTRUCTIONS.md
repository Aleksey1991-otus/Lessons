# Инструкция по установке Rust и проверке проекта

## Установка Rust

Для работы с проектом необходимо установить Rust. Следуйте этим шагам:

### 1. Установите Rust с помощью rustup

Для Linux/macOS:
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

Для Windows:
1. Скачайте и запустите установочный файл с https://win.rustup.rs/
2. Следуйте инструкциям установщика

### 2. Перезапустите терминал или выполните:
```bash
source ~/.bashrc
```

### 3. Проверьте установку:
```bash
rustc --version
cargo --version
```

## Проверка проекта

После установки Rust вы можете проверить проект следующим образом:

### 1. Убедитесь, что вы в корневой директории проекта:
```bash
cd /path/to/your/project
```

### 2. Проверьте зависимости:
```bash
cargo check
```

### 3. Соберите проект:
```bash
cargo build
```

### 4. Запустите проект (необходимы переменные окружения):
```bash
cargo run
```

## Установка переменных окружения

Перед запуском проекта создайте файл `.env` в корне проекта:
```bash
cp .env.example .env
```

Затем отредактируйте файл `.env`, добавив реальные значения:
- TELEGRAM_BOT_TOKEN: токен вашего Telegram-бота
- NEWS_API_KEY: API-ключ от NewsAPI

## Возможные проблемы и решения

### Проблема: "command not found: cargo"
Решение: Убедитесь, что Rust установлен правильно и переменные окружения настроены.

### Проблема: "error: toolchain 'stable' is not installed"
Решение: Выполните команду:
```bash
rustup install stable
rustup default stable
```

### Проблема: "error: failed to get lock"
Решение: Закройте другие терминалы, работающие с тем же проектом, или удалите файлы блокировок:
```bash
rm -rf target/
```

## Проверка функциональности

После успешной сборки проекта вы можете протестировать бота:

1. Запустите бота командой `cargo run`
2. В Telegram найдите вашего бота и начните с команды `/start`
3. Введите тему для поиска новостей (например, "технологии")
4. Проверьте навигацию между новостями с помощью команд "следующая" и "предыдущая"

Все основные функции бота должны работать корректно.
